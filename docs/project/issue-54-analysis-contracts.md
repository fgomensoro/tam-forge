## Contracts
All IDs follow existing positive integer activity/attempt/artifact identity, excluding booleans and numeric strings. Rubric/config keys follow existing VersionKey/Slug patterns and max64; require activity_id, attempt_id, config_version_key, rubric_slug and rubric_version. Artifact references carry positive immutable_version and lowercase SHA256. Attempt text references carry the attempt ID and commitment SHA256. No audio bytes, source URLs, model credentials or mutable source paths. Schema structure does not establish consent, existence, ownership or publication eligibility.

Reference union: attempt_text (attempt_id, commitment_sha256, json_pointer, start_codepoint, end_codepoint); artifact_text (artifact_id, immutable_version, sha256, text_kind written/raw_transcript/corrected_transcript, start_codepoint,end_codepoint); artifact_time (artifact_id,immutable_version,sha256,start_ms,end_ms). The attempt JSON pointer uses RFC6901 syntax rooted strictly below /output/, max512 characters, and selects a decoded string in the committed canonical envelope. Validate pointer syntax/root structurally; later evidence resolution proves it selects learner evidence rather than prompt/audience/context. Integer ranges nonnegative, start<end with exclusive end; text indexes Unicode code points without normalization, at most16Mi codepoints; time at most86400000ms. Artifact text offsets index exact UTF-8-decoded plain text without normalization; structured transcript artifacts require an explicit future locator/version. Written scoring requires text references, never manufactured time ranges. Raw transcript references remain raw; do not score grammar/vocabulary errors from unverified raw ASR text in v1.

Scored dimensions require Decimal score0–4, finite confidence0–1 on each supporting observation, nonblank rubric rationale <=2048 characters, and1–16 observations. Each observation has nonblank statement<=2048, attribution observed_content/user_stated/inferred/unknown, availability available/unavailable, references up to16 with no duplicates. Scored support must be available, have references and not unknown; inferred/user_stated identity is preserved for downstream policy, never relabeled observed. Measured attribution is rejected in v1 because no measurement contract exists yet; do not invent metrics or speech integration. Unavailable/not_applicable dimensions have null score and required bounded reason code and explanation<=2048; no invented scores or overall aggregate. Payload encoded canonical JSON <=1MiB.

English dimensions are exactly communication_effectiveness,fluency,accuracy,vocabulary,pronunciation_intelligibility,listening, as explicit named model fields. TAM dimensions are exactly correctness,structure,relevance,customer_judgment,technical_reasoning,business_framing,trade_offs,audience_adaptation,decision_quality. Reject cross-domain fields, missing dimensions, accent scoring and ASR confidence used as a score. No new weights or rubric config. Existing portfolio0–20 remains unchanged.

English v1 fluency always unavailable/speech_pipeline_unavailable; pronunciation always unavailable/pronunciation_not_measured. Listening is not_applicable for written/monologue evidence, unavailable for unvalidated interactive evidence. Require source_mode written/monologue_transcript/interactive_transcript to make this distinction explicit; no flag enables speech scoring. Only prepared written/corrected transcript text can support the three text English dimensions. TAM supports prepared text judgments, not speech claims. All-unavailable payloads are valid. Existing protocol package gains explicit pydantic dependency using the already locked compatible version; update uv.lock normally, with no unrelated upgrades.
